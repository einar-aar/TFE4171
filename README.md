The first warning is almost always a problem. Latches often lead to undefined behavior and are usually the result of incorrect design, often when not all variables are assigned in all paths in a combinational circuit.

The next two warnings are dead logic. The synthesis tool has created cells that do not drive anything and therefore do nothing other than take up space. It may also be that we actually want these cells to do something, but cannot determine what that might be.

The last two warnings simply state that we do not have resources in the library to analyze “Leakage Power” and “internal power”, so we cannot rely on power analysis.

I assume that we only care about the first warning. The solution here is to assign a value to rd_data even if the if check fails, so that we do not need to remember the previous value in a latch. We simply set rd_data = '0. Also changed from '<=' to '=', since combinational circuits do not allow the former. After new synthesis, the warning was removed.
